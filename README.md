# Make the AI Judge Laugh: Developer Excuses

One funny single-line excuse a developer gives when code breaks in production:

> I didn't break production — I just gave the bug a bigger audience.

`main.py` writes this line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`).
